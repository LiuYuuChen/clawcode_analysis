## Architecture Overview

本段覆盖权限系统的两大子系统：

**1. 初始化管线** (`permissionSetup.ts`, 1532行)：
```
CLI 启动
  → initialPermissionModeFromCLI (解析 --permission-mode 参数)
  → initializeToolPermissionContext (L872)
    → transitionPermissionMode (模式切换)
    → stripDangerousPermissionsForAutoMode (危险权限移除)
    → loadAllPermissionRulesFromDisk (加载规则)
    → buildToolPermissionContext (构建上下文)
```

**2. Auto Mode AI 分类器** (`yoloClassifier.ts`, 1495行)：
```
hasPermissionsToUseTool (auto mode branch)
  → classifyYoloAction (L1012)
    → buildTranscriptForClassifier (构建对话历史)
    → buildYoloSystemPrompt (构建系统提示词)
    → LLM API call (Anthropic/External 分类器)
    → 解析分类结果 (allow/deny)
```

**3. 文件系统权限** (`filesystem.ts`, 1777行)：
```
hasPermissionsToUseToolInner (file tool branch)
  → checkPathSafetyForAutoEdit (路径安全检查)
  → pathInAllowedWorkingPath (工作目录验证)
```
