## File Details

### src/QueryEngine.ts (1295 lines) — DEEP

**class QueryEngine** — 每个会话一个实例，跨 turn 持久状态

**Constructor** (`QueryEngineConfig`):
- 初始化 `messages: Message[]`（会话消息历史）
- 创建 `abortController`（中断控制）
- 加载 `tools: Tools`（工具注册表）
- 保存 `sessionId`, `cwd`, `model` 等配置

**submitMessage(prompt, options)** — AsyncGenerator&lt;SDKMessage&gt;:
1. `fetchSystemPromptParts()` → 获取 systemPrompt 模板 + userContext + systemContext
2. `processUserInput(prompt)` → 处理 slash commands 和 attachments
3. `loadAllPluginsCacheOnly()` + `getSlashCommandToolSkills()` → 插件加载
4. `buildSystemInitMessage()` → yield SDK init message
5. `query()` → 进入核心循环（**关键调用点 L675**）
6. for-await 消费 query() yield 的消息流：
   - `assistant` → yield SDK AssistantMessage
   - `user` → yield SDK UserMessage（tool results）
   - `compact_boundary` → yield CompactBoundaryMessage
   - `attachment` → yield AttachmentMessage
   - `stream_event` → yield StreamEvent（text deltas）
7. `updateUsage()` / `accumulateUsage()` → 跟踪 API token 使用量
8. `recordTranscript()` → 持久化 transcript
9. 处理：max_turns_reached、structured_output、snip boundary replay

**QueryEngineConfig** 关键字段：
- `model: string` — 主循环模型
- `cwd: string` — 工作目录
- `tools: Tools` — 注册工具列表
- `messages?: Message[]` — 初始消息（恢复会话用）
- `abortController?: AbortController` — 外部中断控制
- `systemPrompt?: string[]` — 自定义 system prompt
- `customSystemPrompt?: string` — 完全替代默认 prompt

### src/utils/queryContext.ts (179 lines) — SUPPORTING

**fetchSystemPromptParts()** — 构建 API 请求的 cache-key 前缀：
- `defaultSystemPrompt`: 调用 `getSystemPrompt()` + MCP 动态 sections
- `userContext`: 调用 `getUserContext()`（cwd, os, shell 等）
- `systemContext`: 调用 `getSystemContext()`（项目信息）
- `customSystemPrompt` 时跳过默认构建

**依赖注入设计**：此文件单独存在是为了避免循环依赖（systemPrompt.ts 和 sideQuestion.ts 若导入 context.ts 会产生循环）。

### src/utils/processUserInput/processUserInput.ts (605 lines) — SUPPORTING

**processUserInput()** — 用户输入预处理管线：
- Slash commands 路由（`/help`, `/clear`, `/compact` 等）→ 调用对应 command handler
- File attachments 解析（图片、PDF、文档）→ 生成 attachment messages
- Image resize（大图自动压缩到 API 限制内）
- 返回处理后的 `Message[]` 或 null（无输入修改时）
