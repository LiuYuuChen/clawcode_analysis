### Representative Deep Trace: [`src/commands/help/index.ts`](/src/src/commands/help/index.ts.md)

```typescript
import type { Command } from '../../commands.js'
const help = {
  type: 'local-jsx',
  name: 'help',
  description: 'Show help and available commands',
  load: () => import('./help.js'),
} satisfies Command
export default help
```

**Pattern**: 每个 command 的 `index.ts` 导出 `{ type, name, description, load } satisfies Command`。
- `type`: `'local'` | `'local-jsx'` | `'remote'`
- `name`: 斜杠命令名（如 'clear', 'help', 'compact'）
- `description`: 一句话描述
- `load`: 懒加载函数，动态导入实际实现
- 实现文件导出 `call` 函数（`LocalCommandCall` 或 `LocalJsxCommandCall` 类型）
