Architecture Overview ​

ML-09-2 覆盖 Bridge 子系统的传输、消息处理与远程控制层：

  1. 传输抽象（replBridgeTransport.ts）：统一 v1 HybridTransport(WS+POST) 和 v2 SSE+CCR 双通道接口
  2. 消息处理（bridgeMessaging.ts + inboundMessages.ts + inboundAttachments.ts）：双向消息解析、控制请求路由、文件附件下载
  3. 远程控制主循环（bridgeMain.ts）：claude remote-control 独立持久服务器，多会话 worker 管理
  4. 会话管理（sessionRunner.ts + createSession.ts）：子进程生命周期 + API 会话创建/归档
