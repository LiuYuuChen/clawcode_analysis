## Main Line Summary

ML-06 覆盖 Claude CLI 的完整认证与会话管理管线：
1. **OAuth 2.0 PKCE 流程**：从授权 URL 生成 → 浏览器回调 → token 交换 → profile 获取 → 持久化
2. **认证中枢**：`auth.ts` 统一管理 4 种认证源（OAuth token / API key / AWS STS / GCP），提供 55+ 导出函数
3. **初始化编排**（交叉引用 init.ts）：populateOAuth → policyLimits → remoteSettings → telemetry
4. **会话管理**：`/login` 命令触发 OAuth 登录 → 登录后刷新 policyLimits/remoteSettings/GrowthBook/trustedDevice/authVersion
5. **安全存储**：macOS Keychain → 文件描述符 → 明文三级降级存储策略
