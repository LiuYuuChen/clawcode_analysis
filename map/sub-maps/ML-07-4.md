# Sub-Map: ML-07-4 TUI 渲染与交互 (Stage 4: Hooks 层)

## Overview

Stage 4 包含 REPL 组件使用的全部 39 个自定义 hooks。这些 hooks 封装了从快捷键处理、会话管理到网络轮询等各类副作用逻辑，是 REPL.tsx 编排能力的核心支撑层。

### Hooks 分类

**会话管理 Hooks**:
- useReplBridge: 核心查询桥接，连接 REPL UI 与 QueryEngine
- useRemoteSession: 远程会话管理
- useDirectConnect: 直连模式
- useSSHSession: SSH 会话

**快捷键 Hooks**:
- useGlobalKeybindings: 全局快捷键注册
- useCommandKeybindings: 命令模式快捷键
- useCancelRequest: 请求取消处理

**网络/轮询 Hooks**:
- useInboxPoller: 收件箱轮询 + 权限轮询
- useSwarmPermissionPoller: Swarm 权限轮询

**UI 状态 Hooks**:
- useSearchInput: 搜索输入管理
- useAssistantHistory: 历史记录
- useSessionBackgrounding: 会话后台管理
- useBackgroundTaskNavigation: 后台任务导航

**工具/集成 Hooks**:
- useManagePlugins: 插件管理
- useTasksV2: 任务系统 V2
- useIdeSelection: IDE 选区
- useIDEIntegration: IDE 集成

### Key Hook Details

**useReplBridge.tsx** (723 lines):
- 核心查询桥接 hook，连接 REPL UI 与 QueryEngine
- 管理 submit 流程：构建 UserMessage → 调用 QueryEngine.submit()
- 处理流式响应：监听 onAssistantMessage/onToolUse/onToolResult 回调
- 管理中断：AbortController 集成
- 返回 onSubmit/onCancel/getIsLoading/setMessages 等 API

**useInboxPoller.ts** (969 lines):
- 收件箱轮询：周期性检查新消息（Swarm inbox）
- 权限轮询：检查待处理的权限请求
- 合并轮询：统一 setInterval 管理
- 消息合并：新消息追加到 messages 数组
- 支持暂停/恢复（transcript 模式暂停）

**useRemoteSession.ts** (605 lines):
- WebSocket 连接管理
- 远程会话状态同步
- 输入转发：本地输入 → 远程 QueryEngine
- 消息接收：远程响应 → 本地渲染

**useGlobalKeybindings.ts** (249 lines):
- ink useInput 的封装
- 注册全局快捷键映射表
- 处理 Escape/ctrl+c/ctrl+z/ctrl+o/ctrl+r 等
- 支持 conditional activation（仅在特定状态下响应）
