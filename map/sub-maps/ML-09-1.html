Sub-Map: ML-09-1 Bridge 远程模式 (Stage 1: REPL 连接层) ​

Entry Point ​

  • File: src/bridge/initReplBridge.ts
  • Function: initReplBridge() — REPL 专用桥接入口包装器
  • Confirmed: YES

Architecture Overview ​

ML-09-1 覆盖 Bridge 子系统的连接建立层：从 REPL 或 SDK 触发桥接初始化，经过权限/策略/OAuth 多层门控，建立与 claude.ai 服务端的双向通信通道。

核心双模式架构：

  • v1 环境模式（replBridge.ts::initBridgeCore）：Environments API → register → poll work → HybridTransport(WS)
  • v2 无环境模式（remoteBridgeCore.ts::initEnvLessBridgeCore）：POST /v1/code/sessions → POST /bridge → SSE+CCR

由 GrowthBook tengu_bridge_repl_v2 门控切换。
