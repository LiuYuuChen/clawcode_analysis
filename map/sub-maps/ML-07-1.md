### Screen 状态机
```
type Screen = 'prompt' | 'transcript'
```
- `prompt`: 正常交互模式，显示 Messages + PromptInput
- `transcript`: 回放模式（Ctrl+O），显示全量消息 + 搜索栏

### 核心渲染路径 (prompt 模式)
```
REPL → GlobalKeybindingHandlers
     → CommandKeybindingHandlers
     → ScrollKeybindingHandler
     → CancelRequestHandler
     → FullscreenLayout
        ├─ Messages (消息列表)
        ├─ SpinnerWithVerb (加载指示)
        ├─ TaskListV2 (任务面板，条件渲染)
        ├─ ElicitationDialog (MCP 请求，modal)
        ├─ PromptDialog (工具确认，modal)
        ├─ CostThresholdDialog (费用确认，modal)
        ├─ IdleReturnDialog (空闲返回确认，modal)
        ├─ MessageSelector (消息选择器，modal)
        └─ PromptInput (用户输入)
```

### 核心渲染路径 (transcript 模式)
```
REPL → GlobalKeybindingHandlers
     → CommandKeybindingHandlers
     → ScrollKeybindingHandler
     → CancelRequestHandler
     → FullscreenLayout
        ├─ Messages (全量消息，showAll=true)
        └─ TranscriptSearchBar (搜索栏)
```
