## Architecture Overview

权限系统是 Claude Code 的安全核心。每个工具执行前必须经过权限检查。

**核心流程**：
```
useCanUseTool (React Hook)
  → hasPermissionsToUseTool (规则匹配)
    → checkRuleBasedPermissions (allow/deny/ask 三路)
    → 模式转换 (dontAsk→deny, auto→AI classifier)
    → UI 提示 (PermissionRequest 组件)
  → runPreToolUseHooks (外部 Hook 拦截)
```

**权限决策树**：
```
hasPermissionsToUseToolInner(tool, input, context)
  ├─ always allowed? → allow
  ├─ sandbox allowed? → allow  
  ├─ checkRuleBasedPermissions()
  │   ├─ deny rule match → deny
  │   ├─ allow rule match → allow
  │   └─ no rule match → ask
  ├─ mode == dontAsk → deny (ask→deny 转换)
  ├─ mode == auto → AI classifier → allow/deny
  └─ mode == default → ask user (UI prompt)
```
