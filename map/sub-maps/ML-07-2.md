```
   └─ ...
```

### Key Symbols Detail

**Messages.tsx**:
- `Messages()`: 主组件，接收 messages/toolJSX/isBriefOnly 等 props
- 按消息类型分派：UserMessage → UserTextMessage，AssistantMessage → 渲染 text+thinking+tool_use
- 管理 `streamingText` 实时渲染和 `streamingThinking` 折叠显示
- `verbose` 模式下展开所有工具详情

**PromptInput.tsx** (系统最大组件之一，2339 行):
- `PromptInput()`: 主组件，处理多行文本输入
- 三种模式: `prompt` (正常)、`vim` (vim 模式)、`multiline` (多行编辑)
- Tab 补全系统：文件路径补全、命令补全、slash 命令补全
- 支持 Paste Mode、dry-run 模式、图片粘贴
- Subtle prompt 模式：简洁显示，仅显示最新消息

**VirtualMessageList.tsx**:
- 基于 `@tanstack/react-virtual` 的虚拟滚动实现
- 消息高度动态计算 + 缓存
- `stickyBottom` 模式：新消息时自动滚到底部
- 搜索高亮位置跳转

**FullscreenLayout.tsx**:
- 双栏布局：主内容区 + 输入区
- 可选的 divider 分割线（可拖拽调整比例）
- Modal overlay 层：居中显示 dialog
- 底部浮动通知

**ScrollKeybindingHandler.tsx**:
- 处理 j/k/g/G/C-d/C-u/C-f/C-b 等 vim 风格快捷键
- 消息间跳转（数字前缀 + j/k）
- 搜索结果导航（n/N）
- 滚动事件合并（requestAnimationFrame）

**Spinner.tsx**:
- 多种视觉模式：spinning、pulsing、dots、progress bar
- 显示 token 使用统计和响应速率
- `SpinnerWithVerb` 包装：显示当前动作（"Thinking", "Reading", "Writing" 等）

**ElicitationDialog.tsx** (1169 行):
- MCP Elicitation 协议实现
- 渲染 JSON Schema 表单
- 支持文本输入、选择器、文件上传等表单类型
- 带超时倒计时和取消按钮
