- Key architectural insight:
  1. **四路 Provider 工厂**: client.ts 根据环境变量(CLAUDE_CODE_USE_BEDROCK/VERTEX/FOUNDRY)路由到 4 种 Anthropic SDK 配置
  2. **AsyncGenerator 重试引擎**: withRetry.ts 以 generator 模式实现，支持 yield 错误让调用方决策，最多 10 次重试含 529 过载退避、模型降级(Opus→Sonnet)、context overflow 自适应
  3. **errors.ts 是最大单文件(1207行)**: 12+ 种错误类型分类 + 用户友好消息生成，是所有错误展示的单一来源
  4. **gateway 检测**: logging.ts 检测 7 种 API gateway(litellm/helicone/portkey/cloudflare/kong/braintrust/databricks)影响遥测上报
  5. **双层缓存模式**: metricsOptOut.ts(1h内存+24h磁盘)和 grove.ts(24h memoize)展示了项目统一的缓存策略
  6. **emptyUsage.ts 的依赖隔离**: 单独提取零值常量，避免 bridge 路径引入整个 API 错误处理链(errors→messages→BashTool→全局)
