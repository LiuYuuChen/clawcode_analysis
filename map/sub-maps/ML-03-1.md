## Key Insights

1. **`buildTool()` + `TOOL_DEFAULTS`**: 所有工具通过 `buildTool()` 工厂创建，填充安全默认值（isEnabled→true, isConcurrencySafe→false, isReadOnly→false）。这确保新增工具不会意外遗漏安全方法。

2. **三层过滤管线**: `getAllBaseTools()` (feature flags) → `getTools()` (deny rules + REPL + isEnabled) → `assembleToolPool()` (merge MCP + dedup)。每一层都缩减工具集。

3. **并发安全分区**: `partitionToolCalls()` 按工具的 `isConcurrencySafe(input)` 动态分区，保守策略（解析失败视为不安全）。并发安全工具最多 10 个并行。

4. **交叉引用密集**: ML-03 的 Layer 1 与 ML-02 (查询引擎) 紧密耦合 — `toolOrchestration.ts` 和 `StreamingToolExecutor.ts` 是 ML-02 的直接子模块。ML-01 在 bootstrap 时调用 `tools.ts`。
