### src/query.ts (1729 lines) — DEEP (核心状态机)

**query()** (L219) — async generator，包装 queryLoop()：
- 初始化 State（messages, toolUseContext, tracking, turnCount=0）

- 返回 `{ reason: string }` 终止信号

**queryLoop()** (L241-1729) — `while(true)` 循环，核心状态机：

**State 结构** (9 个可变字段)：
```
State = {
  messages: Message[],
  toolUseContext: ToolUseContext,
  autoCompactTracking: AutoCompactTrackingState,
  maxOutputTokensRecoveryCount: number,
  hasAttemptedReactiveCompact: boolean,
  pendingToolUseSummary: Promise<...>,
  maxOutputTokensOverride: number | undefined,
  stopHookActive: boolean,
  turnCount: number,
  transition: { reason: string }
}
```

**每轮迭代完整流程**：
1. **消息预算裁剪**：`applyToolResultBudget()` 裁剪过长 tool_result
2. **四级压缩管线**（按优先级顺序执行）：
   - `snipCompactIfNeeded()` — 剪切历史尾部（feature-gated）
   - `deps.microcompact()` — 缓存编辑方式删除工具结果
   - `contextCollapse.applyCollapsesIfNeeded()` — 上下文折叠（feature-gated）
   - `deps.autocompact()` — 完整对话压缩（→ autoCompact.ts → compact.ts）
3. **阻塞检查**：`tokenCountWithEstimation()` 超限时 yield blocking_limit
4. **API 调用**：`deps.callModel()` → 流式请求（→ ML-02-3）
5. **流式响应消费**：for-await 遍历 stream：
   - `text_delta` → assistant text chunks
   - `tool_use` → tool use blocks
   - `message_stop` → 检查 stop_reason
6. **错误恢复**：
   - `FallbackTriggeredError` → 切换 fallbackModel 重试（→ BL-02-02）
   - `withheld` + prompt-too-long → collapse drain → reactive compact（→ BL-02-03）
   - `max_output_tokens` → escalate 到 64k（→ BL-02-02）
7. **Stop hooks**：`handleStopHooks()` 评估 blocking errors
8. **工具执行**：StreamingToolExecutor.getRemainingResults() 或 runTools()
9. **工具摘要**：`generateToolUseSummary()` 异步生成（不阻塞）
10. **Attachment 注入**：
    - `getAttachmentMessages()` — queued commands + file changes
    - `pendingMemoryPrefetch` — memory prefetch
    - `pendingSkillPrefetch` — skill discovery prefetch
11. **Continue 决策**：构建下一个 State → `continue`

**7 个 Continue 路径**：
| 路径 | reason | 触发条件 | State 修改 |
|------|--------|----------|-----------|
| next_turn | 'next_turn' | 工具执行完成，有 tool results | messages 更新, turnCount++ |
| collapse_drain_retry | 'collapse_drain_retry' | prompt-too-long + context collapse drain | messages 更新, hasAttemptedReactiveCompact=true |
| reactive_compact_retry | 'reactive_compact_retry' | prompt-too-long + reactive compact | messages 更新, hasAttemptedReactiveCompact=true |
| max_output_tokens_escalate | 'max_output_tokens_escalate' | max_output_tokens 首次 | maxOutputTokensOverride=64k |
| max_output_tokens_recovery | 'max_output_tokens_recovery' | max_output_tokens + recovery message 注入 | maxOutputTokensRecoveryCount++ |
| stop_hook_blocking | 'stop_hook_blocking' | stop hook 阻止继续 | stopHookActive=true |
| token_budget_continuation | 'token_budget_continuation' | token 预算检查通过 | turnCount++ |

**终止条件**：
- `completed` — stop_reason='end_turn' 且无 tool_use
- `aborted` — abortController signal
- `aborted_tools` — 中断发生在工具执行期间
- `max_turns` — 超过 maxTurns 限制
- `hook_stopped` — stop hook 阻止继续
- `blocking_limit` — token 计数超限且压缩失败

**终止返回值**：`{ reason: string, turnCount?: number }`
