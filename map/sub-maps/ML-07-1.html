Sub-Map: ML-07-1 TUI 渲染与交互 (Stage 1: REPL 入口 + Ink 框架层 + 状态管理 + 快捷键) ​

Entry Point ​

  • File: src/screens/REPL.tsx
  • Function: export function REPL({...
  • Line: 604
  • Confirmed: YES — 主函数从第 604 行开始，接收 ~30 个 Props 参数，是系统最大的组件文件

Overview ​

REPL.tsx 是整个 TUI 系统的超级编排入口。它导入了 225 个本地模块，自身包含 5,061 行代码，承担了从 ink 框架初始化、组件树构建、用户输入处理到会话管理的全部编排职责。Stage 1 覆盖 REPL 入口本身、ink 框架适配层、全局状态管理和快捷键系统。

REPL.tsx 内部结构 ​

  • Lines 1-48: Imports（225 个本地导入）
  • Lines 49-310: Feature-flag 条件导入（useVoice, useProactive, useScheduledTasks 等）
  • Lines 311-603: 辅助函数（median, TranscriptModeFooter, TranscriptSearchBar, AnimatedTerminalTitle）
  • Lines 604-5061: 主函数 REPL()
    • Lines 604-700: Props 解构 + useAppState 调用（15+ 状态字段）
    • Lines 700-950: 初始化 hooks（useMainLoopModel, useSkillsChange, useMemo(getTools)）
    • Lines 950-1400: Session hooks + remote session setup
    • Lines 1400-3800: 事件处理函数、辅助 hooks、状态计算
    • Lines 3800-4450: useReplBridge + useInboxPoller 核心编排
    • Lines 4450-5061: JSX return — 两分支：transcript 模式和 prompt 模式

Screen 状态机 ​

type Screen = 'prompt' | 'transcript'
  • prompt: 正常交互模式，显示 Messages + PromptInput
  • transcript: 回放模式（Ctrl+O），显示全量消息 + 搜索栏

核心渲染路径 (prompt 模式) ​

REPL → GlobalKeybindingHandlers
     → CommandKeybindingHandlers
     → ScrollKeybindingHandler
     → CancelRequestHandler
     → FullscreenLayout
        ├─ Messages (消息列表)
        ├─ SpinnerWithVerb (加载指示)
        ├─ TaskListV2 (任务面板，条件渲染)
        ├─ ElicitationDialog (MCP 请求，modal)
        ├─ PromptDialog (工具确认，modal)
        ├─ CostThresholdDialog (费用确认，modal)
        ├─ IdleReturnDialog (空闲返回确认，modal)
        ├─ MessageSelector (消息选择器，modal)
        └─ PromptInput (用户输入)

核心渲染路径 (transcript 模式) ​

REPL → GlobalKeybindingHandlers
     → CommandKeybindingHandlers
     → ScrollKeybindingHandler
     → CancelRequestHandler
     → FullscreenLayout
        ├─ Messages (全量消息，showAll=true)
        └─ TranscriptSearchBar (搜索栏)
