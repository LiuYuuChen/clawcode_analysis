## File Details

### src/utils/messages.ts (5512 lines) — SUPPORTING (最大文件)

**消息格式转换管线**：

**normalizeMessagesForAPI(messages)** → `BetaMessageParam[]`：
- 遍历 Message[] → 按 role 分发处理
- assistant messages → `assistant` role BetaMessageParam
- user messages → `user` role BetaMessageParam
- tool results → 嵌入到 user message 的 tool_result block

**normalizeContentFromAPI(content)** → 内部 ContentBlock[]：
- API BetaContentBlock → 内部 TextBlock/ImageBlock/ToolUseBlock/ToolResultBlock
- 处理 connector text blocks（特殊渲染标记）

**ensureToolResultPairing(messages)** — 确保 tool_result 与 tool_use 配对：
- API 要求 assistant message 的每个 tool_use 必须在后续 user message 中有对应 tool_result
- 缺失的 tool_result 自动补充 error result
- 多余的 tool_result（无对应 tool_use）被移除

**createUserMessage(content, options)** → `UserMessage`：
- 构建标准用户消息
- 处理 attachments、images、file references

**createAssistantAPIErrorMessage(content)** → `SystemAPIErrorMessage`：
- 构建 API 错误消息（用于错误恢复场景）

**消息截断与裁剪**：
- `truncateToolResult()` — 裁剪过长 tool_result
- `applyToolResultBudget()` — 总体 tool_result 预算管理
- `snipCompactIfNeeded()` — 历史尾部剪切

**特殊消息类型**：
- `CompactBoundaryMessage` — 压缩边界标记
- `AttachmentMessage` — 文件附件消息
- `SystemAPIErrorMessage` — 系统 API 错误消息

### src/utils/api.ts (718 lines) — SUPPORTING

**toolToAPISchema(tool)** → `BetaToolUnion`：
- 将内部 Tool 接口转换为 Anthropic API 的 tool schema 格式
- 支持 bash, text_editor, computer_ 等特殊工具类型
- Cache scope 标记（`CacheScope`）

**splitSysPromptPrefix(prompt)** → `{ prefix, rest }`：
- 拆分 system prompt 的前缀（cache key 部分）和其余内容
- 用于 API 的 prompt caching

**getAttributionHeader()** → attribution string：
- API 请求的 attribution header（用户 ID、版本等）

### src/utils/queryHelpers.ts (552 lines) — SUPPORTING

**getAttachmentMessages()** — Attachment 注入：
- 检查 queued commands → 生成 attachment messages
- 检查 file changes → 生成 file change notifications
- 返回 `Message[]` 注入到 query loop

**pendingMemoryPrefetch** — Memory 预获取：
- 异步预获取 memory context
- 不阻塞主循环

**pendingSkillPrefetch** — Skill 发现预获取：
- 异步扫描可用 skills
- 结果缓存供后续 turn 使用
